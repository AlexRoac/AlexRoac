## Featured Project

### 🚌 RuTampico

A web and mobile platform designed to improve the way people understand and use **public transportation in Tampico, Tamaulipas**.

RuTampico focuses on making local transportation information easier to access by allowing users to explore routes, visualize them on a map and plan their trips.
